# 仕様

動作環境:Windows (11)  
必要ライブラリ:`pygame-ce`  

## 基本

**レジスタはA~Dの4本。**  
**メモリは0x0000~0xFFFFの16bit、65536個。**  
***スタックはメモリの0xFFFFから2バイトずつ(上位→下位の順)で積む***  
**計算処理のたびにゼロフラグ、キャリーフラグが更新される。**  

## つかいかた

**基本的に、main.pyを起動してbiosを経由、os.sema3を読み込む。**

### OSの操作

`ENTER>`　の先にコマンドを打ち込む(大文字小文字を区別する)。

***コマンド集:***
| コマンド | 効果 |
|---|---|
|exit|OSを終了する。|
|file|打ち込んだファイル名のファイルをdataフォルダから読み込んで実行する。|
|color|描画テストをする。|

ファイルは原則0x2000に読み込む。(プログラムを書くとき、OSから起動する前提のファイルは、.org 0x2000などで、ロード位置を0x2000に指定すること。)  

描画テストはwasdで操作して、1234で色を変えて、0で終了。  

たまに反応しないことがあるので、その場合は打ち直し。  

## ヘッダー

専用の拡張子の `.sema3` は、ヘッダーに  
**ThisIsOh**(**8 byte**)  + バージョン番号(**1 byte**) + ロード位置アドレス(**2 byte**) + 開始位置アドレス(**2 byte**)  
の**13 byte**をつける。

## I/Oポート

IN/OUT命令で扱う。基本的に、レジスタを介して外部と*1バイトずつ*やりとりができる

### ポート集

| ポート番号 | 関数 | 説明 |
|---|---|---|
| 0x00 | out_number | コンソールに10進数で1バイト表示する。 |
| 0x01 | in_char | 入力を待ち、下位の1バイト分を返す。|
| 0x01 | out_char | コンソールにASCII文字列で1バイト表示する。|
| 0x02 | in_key | 待たずにキーボード入力を受け取る。|
| 0x03 | run_display | (OUT)描画用のウィンドウを起動する。 |
| 0x04 | kill_display | (OUT)描画用のウィンドウを閉じる。 |
| 0x05 | F.out_name | ファイルの名前として1バイトを送信する。 |
| 0x06 | F.in_byte | ファイルの内容の1バイトを送信する。 |
| 0x07 | F.in_status | ファイルの内容を受け取れるかチェックする。 |
| 0x08 | wait_frames | (OUT)1/60秒待つ。 |
| 0x09 | read_held | (IN)キーが押されているか確認する。 |
| 0x0A | read_edge | (IN)キーが押された瞬間を確認する。 |
| 0x0B | set_slot | (OUT)キースロットを指定する。 |
| 0x0C | set_key | (OUT)指定されているキースロットにキーを設定する。 |
| 0x0D | snd_sel | (OUT)サウンドデバイスに送るものを記録する([`後述`](#サウンドデバイス))。 |
| 0x09 | snd_val | (OUT)サウンドデバイスに設定を送る([`後述`](#サウンドデバイス))。 |

#### キー入力デバイス
**キー入力をリアルタイムで受け取るデバイス(0x09,0x0A,0x0B,0x0C)。**  
スロットに設定されたキー入力をビットで返す。  

`read_held(0x09)`は入力されていれば１、されていなければ０を返す。  
`read_edge(0x0A)`は入力された瞬間に１、それ以外で０を返す。  
`set_slot (0x0B)`でスロットを指定して、  
`set_key  (0x0C)`でキーの番号をセットする。  

初期状態ではスロット指定は0、スロットの中身は以下のようになっている。  
**[0x26, 0x28, 0x25, 0x27, 0x5A, 0x58, 0x43, 0x56]**  
  **↑     ↓     ←     →     Z     X     C     V**  

***ビットの見た目とリストの順番が逆になっていることに注意。***  
*左から順に1,2,4,8,16,32,64,128になっている。*  

例:
上のスロットで、`↑ , ↓ , z`　を入力した場合、  
帰ってくる値は`0x13`(`0b00010011`,`19`)。  

## サウンドデバイス
上位2ビットでチャンネル指定、下位6ビットで指定。0,音の高さ、1,音色(0~3)
sounddeviceで音源を扱うデバイス(0x0C,0x0D)。
`snd_sel(0x0C)`は、送った値の上位の2ビットからチャンネルを指定する(0b**00**000000)。  
00,01,10,11で4チャンネル指定でき、下位の6ビットで
機能を指定する。
| 番号 | 機能 |
| 0 | 音程を指定する。 |
| 1 | 音色を指定する(4種類)。 |

`snd_val(0x0D)`は、`snd_sel`で指定したところに、`snd_val`に送られた値を入れる。音程や音色を指定するのはここ。


### 想定メモリマップ
0x0000 ~ 0x00FF  
ブートローダー、BIOS  

0x0100 ~ 0x1FFF  
OS  

0x2000 ~ 0x7FFF  
ユーザープログラム領域  
 
0x8000 ~ 0x9FFF  
変数  

0xA000 ~ 0xEFFF  
VRAM領域(E000以降は予備)  

0xF000 ~ 0xFFFF  
スタック領域  



# 命令集
### 記号
- `n`：即値。`0x00` ～ `0xFF` の範囲の値を指定する。  
- `r`：レジスタ番号。`0x00` ～ `0x03` を指定し、それぞれ A、B、C、D レジスタに対応する。  
- `a`：アドレスを表す2バイトの値。リトルエンディアン方式で格納される。
